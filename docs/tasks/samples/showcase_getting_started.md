# 入门示例：本 Demo 做什么

这份文档面向第一次打开本站的工程师。无需了解本仓库内部术语。

## 本 Demo 是什么

这是一个**只读**的本地演示站。你可以：

- 浏览仓库里 `docs/tasks/` 下的说明文档（Markdown）
- 查看本地命令行工具输出的**运行状态**（在「运行状态」页）

页面**不能**改写审批结果，也**不能**代替人工签收。屏幕上看到的内容是展示用投影，不是可写的真值入口。

## 如何本地启动

1. 在本仓库根目录执行 `pnpm install`
2. 执行 `pnpm dev`，浏览器打开提示的本地地址
3. 顶栏可进入：首页、运行状态、文档

合并代码前建议跑通：`pnpm lint` → `pnpm test` → `pnpm build`。

## 如何在「文档」页打开文件

1. 打开顶栏 **文档**
2. 左侧是 `docs/tasks/` 下的文件列表
3. 点击任一文件，右侧会渲染排版后的 Markdown（不是纯文本堆叠）

本页（`docs/tasks/samples/showcase_getting_started.md`）也会出现在该列表中，可作为对照。

## 只读原则（请记住）

- 本站只读浏览说明文档与本地工具状态
- 页面不能改写审批结果
- 不要在浏览器里尝试「批准闸门」之类的写操作——接口会拒绝

## 你可以先做的几件事

- 在首页看完本示例的排版效果
- 到「文档」页打开任意任务说明
- 到「运行状态」页看一眼本地工具返回的 JSON（可选示例数据对照）
