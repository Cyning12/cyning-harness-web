## 边标记（摘要）

| 标记 | 语义 |
|------|------|
| `->` | 同步顺序 |
| `~>` | 异步 / await |
| `=>` | 赋值 / 映射 |
| `?>` | 条件分支 |
| `[ok]` / `[err]` | 成功 / 失败 |
| `::gates` | 门禁 |
| `::triggers` | 触发子流程 |
| `::signoff` | 签收 / 确认持久化 |

## 节点形状（摘要）

| 形状 | 含义 |
|------|------|
| `[[...]]` | 阶段 / 流程块 |
| `[...]` | 操作 |
| `[(...)]` | 数据 / 落盘 |
| `{...}` | 判断 |
| `>...]` | 文档 / 路由指针 |
